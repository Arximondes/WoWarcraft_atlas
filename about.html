About the project

The 'Warcraft Atlas' is an educational interactive atlas of the Warcraft universe.

What is it?

The 'Warcraft Atlas' is a non-commercial educational project dedicated to the Warcraft universe. The site features interactive maps of the main worlds: Azeroth, Draenor, Outland, Argus, and the Shadowlands. Each map is divided into locations: by clicking on any of them, you can read a brief description right on the site or go to a full article on Warcraft Wiki.

How to use

  • Select a world on the main page.
  • Hover over a region — a tooltip with the name will appear.
  • Click on a region — a side panel with an image, description, and a link to the full article will open.
  • Mouse wheel — zoom, drag — navigate the map.
  • The '⤢' button or double-clicking the map resets the zoom.

Sources

The main source of information is Warcraft Wiki — the largest fan encyclopedia for the Warcraft universe. Location descriptions are based on site materials and adapted for the reader.

Map images (textures) for the interactive atlas were taken from the maps.dadesign.ru project.
